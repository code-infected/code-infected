# Hey, I'm Athul 👋

I'm a software engineer from Palakkad, Kerala. I got into engineering because I was genuinely curious about how things work — and I've never really stopped asking that question.

I work across the full stack: backend services, APIs, and AI systems. Not because I had to, but because I actually enjoy all of it. I like understanding the whole picture, from the database query to the UI that renders it to the AI layer that makes it intelligent.

I care about craft. Clean code, clear thinking, and owning what I build from start to finish. I get unreasonably bothered by slow APIs and bad abstractions. I use AI tools every single day as part of how I actually think and build — not as a gimmick.

### 🖥️ Supactl — Native Desktop Client for Supabase
🔗 [github.com/code-infected/supactl](https://github.com/code-infected/supactl)

No native desktop client existed for Supabase. So I built one. Covers the full workflow — SQL editor, table editor, auth user management, storage, RLS policies, realtime event inspector, edge function logs, and migrations — all without opening a browser. Open-source and actively maintained.

`Tauri v2` `React 18` `TypeScript` `Supabase JS SDK` `CodeMirror 6` `Zustand` `Tailwind CSS`
